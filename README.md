**# RTL Mini Projects - Verification Fundamentals**



This repository contains a collection of SystemVerilog verification mini projects focused on developing fundamental verification skills, progressing from self-checking testbenches to Assertion-Based Verification, Functional Coverage, and Constrained-Random Verification.



\-> This repository represents **Phase-2 Cycle-3: Verification Fundamentals** of my RTL learning journey, focused on understanding verification methodologies and applying them to previously developed RTL designs.



The goal of this repository is to:

* Understand fundamental RTL verification concepts
* Develop class-based SystemVerilog verification environments
* Build self-checking testbenches using scoreboards
* Apply transaction-based stimulus generation
* Understand Assertion-Based Verification (ABV)
* Implement SystemVerilog Assertions (SVA)
* Implement Functional Coverage using covergroups and coverpoints
* Apply Constrained-Random Verification (CRV)
* Verify previously developed RTL designs using structured verification environments
